## 1. Motivation

Causal-set SSEE provides a rare same-realization laboratory containing:

- causal order / discreteness;
- a Lorentzian field correlation structure;
- a covariant entanglement observable;
- a source-defined tension between raw volume-law entropy and area-law behavior after additional spectral truncation.

This is methodologically stronger than immediately splicing causal-set kinematics to an unrelated holographic reconstruction.

## 2. Hypothesis

`BH-003 / CSEC`:

> In a physically viable causal/relational quantum-gravity continuum regime, the spectral coarse-graining needed for continuum-like entanglement scaling should be fixed by the native causal/dynamical state and its scale flow, rather than selected by demanding an area law after the fact.

Equivalently, the entanglement regulator should be an output of the same realization.

## 3. Anti-circularity requirement

A spectral threshold `Lambda_spec` is admissible as physical bridge data only if it can be determined **without using the target entropy scaling on the evaluation region**.

Allowed examples in principle:

- a spectral crossover/knee predicted from the global causal-set operator spectrum;
- a threshold derived from causal-set density and a renormalization/coarse-graining law;
- a dynamical fixed-scale relation obtained from the same path-sum/effective action;
- a stability/positivity requirement that uniquely fixes the retained spectral sector.

Forbidden as evidence:

- choosing `Lambda_spec` because it produces an area law on the same data used for validation;
- tuning it independently for each region/horizon;
- importing a continuum cutoff with no same-realization parameter map.

## 4. Prospective holdout test

For a family of independently generated manifold-like causal sets:

1. infer `Lambda_spec` from a training/global object not involving the target subregion entropy law;
2. freeze the rule;
3. compute SSEE on multiple unseen region shapes/sizes/backgrounds;
4. test whether the frozen spectral rule reproduces the expected controlled continuum scaling where that scaling is independently established;
5. record volume-law deviations rather than retuning the threshold.

A successful frozen-rule transfer is much stronger evidence than per-instance area-law fitting.

## 7. Falsification conditions

BH-003 is weakened/rejected in its strong form if:

1. no region-independent spectral rule can be derived without area-law tuning;
2. frozen thresholds fail catastrophically across holdout geometries even inside their declared continuum regime;
3. the required spectral rule is unrelated to causal density/dynamics and remains an arbitrary external regulator;
4. multiple inequivalent regulator rules fit all available observables with no discriminant;
5. the raw volume law survives every independently motivated coarse-graining rule and is shown to be the correct physical UV prediction.

Condition 5 would be scientifically interesting: the bridge would fail, but the result would point toward genuine nonlocal UV entanglement rather than continuum-like area scaling.
