## Parallel stream A — RC-006 EPRL/FK support closure

Source realization: Dittrich–Schnetter–Seth–Steinhaus, arXiv:1609.02429, reduced Euclidean `SU(2)_k x SU(2)_k` EPRL/FK-type intertwiner model.

Source equations used:

`(j+,j-) = ((1+gamma)l/2, (1-gamma)l/2)` (their Eq. 22),

with explicit non-trivial integer-map cases:

- `k=6, gamma=1/3`: `l=3 -> (2,1)`;
- `k=10, gamma=3/5`: `l=5 -> (4,1)`;
- `k=12, gamma=1/3`: `l=3 -> (2,1)`, `l=6 -> (4,2)`.

Test: enumerate exact `SU(2)_k` fusion-support channels generated by pairwise recoupling of source-allowed labels. For each coarse diagonal-SU(2) label `l`, compare the generated `(J+,J-)` envelope with the source EPRL simplicity image `Y_gamma(l)`.

This is a **support-level necessary-condition audit**, not a reproduction of the full q-deformed tensor amplitudes or TNR singular values.

Preregistered questions:

1. Is the raw recoupling envelope strictly larger than the source simplicity image for every non-trivial EPRL case?
2. Does the source-native local simplicity selector lie inside the generated envelope whenever its target label is defined?
3. Does applying that local selector restore the original support rule without using a closure metric?

Positive answers support the *semantic architecture* of BH-004B in RC-006 but do not establish amplitude-level coarse-graining universality.
