## 1. Purpose

BH-002 Causal–Entanglement Metric Reconstruction (CEMR) combines a causal conformal class with quantum-information geometric data. Before promoting any obstruction as new physics, ISQGR must determine what entanglement data can already reconstruct without a causal-set input.

## 2. Important 2026 comparator

Ji-Seong Chae, *Covariant Holographic Entanglement Entropy Inversion to Reconstruct Bulk Geometry* (2026), arXiv:2605.16459.  
https://arxiv.org/abs/2605.16459

The paper develops analytic inversion of covariant holographic entanglement entropy in a stationary HRT setting. For fixed characteristic parameter `kappa=E/J`, entropy data define candidate radial reconstructions. A single classical radial geometry exists only when reconstructions from different characteristic leaves agree in the same radial coordinate.

The source therefore already contains a **cross-leaf integrability/consistency condition internal to the entanglement channel**. It also shows that, in its controlled setting, entanglement data can expose projected bulk light-cone information.

## 3. Consequence for ISQGR

The mere statement

`different entanglement-derived patches/leaves must fit one metric`

is **not sufficient novelty** for CEMR.

Our local residual

`delta_i = log(A_i^obs/A_i[g_bar]) - mean(r)`

remains a useful executable regression test, but its scientific value is presently methodological. To become genuinely inter-school, the causal input must do work that the entanglement inversion does not already do by itself.

## 4. Revised CEMR value criterion

A CEMR result is promoted beyond `BRIDGE_HYPOTHESIS` only if at least one is established:

### C1 — Rank gain

Conditioning on a causally determined conformal class reduces the metric inverse problem rank deficiency or improves identifiability beyond an entanglement-only reconstruction.

### C2 — Independent obstruction

Causal data exclude an entanglement-compatible metric branch that cannot be excluded by entanglement data alone.

### C3 — Scale completion

Causal order fixes conformal/light-cone structure while an independently calibrated entanglement/area channel fixes the remaining local scale in a regime where neither channel alone determines the same full metric.

### C4 — Cross-channel falsification

Each channel is internally self-consistent, but the two channels cannot be embedded into one metric. This is a genuinely joint obstruction.

If none of C1–C4 occurs, CEMR is redundant rather than a new bridge.

## 5. Older entanglement-metric comparator

S. R. Roy, D. Sarkar, *Bulk metric reconstruction from boundary entanglement* (2018), arXiv:1801.07280.  
https://arxiv.org/abs/1801.07280

That construction extracts bulk metric information from CFT modular-Hamiltonian data and demonstrates selected examples, with residual conformal-scale structure in the stated proof-of-principle settings.

This strengthens the need to phrase BH-002 as an **information-complementarity question**, not as a claim that entanglement has never reconstructed a metric.

## 6. Quantum-correction firewall

Classical RT/HRT area inversion is not the full quantum regime. Quantum extremal surfaces extremize generalized entropy, not area alone. Therefore a CEMR finite-area inversion must carry a nuisance/correction layer before being interpreted beyond leading semiclassical order.

Initial source anchors:

- N. Engelhardt, A. C. Wall, *Quantum Extremal Surfaces* (2014), arXiv:1408.3203.
- C. Akers, G. Penington, *Leading order corrections to the quantum extremal surface prescription* (2020), arXiv:2008.03319.
