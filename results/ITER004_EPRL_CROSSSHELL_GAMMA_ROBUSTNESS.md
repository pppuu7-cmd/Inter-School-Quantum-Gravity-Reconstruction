## Exhaustive map

For each gamma:

- all `10` choices of two open intertwiner axes are evaluated;
- all `8 x 8` fixed-boundary `Dl1 -> Dl0` pairs are evaluated;
- total `640` cases per gamma;
- the rank-1 retained projector is learned only from the `Dl=0` all-zero train slice for the relevant open-axis pair and is then frozen;
- each case is compared with `512` Haar rank-matched controls.

Symmetry-related slices are descriptive robustness cases, not independent statistical trials.

The effect is not universal over all slices: only about `62-68%` of exhaustive cases have return improvement above one. This is informative because it rules out the trivial interpretation that every rank-1 subspace of these tiny matrices automatically beats the controls.
