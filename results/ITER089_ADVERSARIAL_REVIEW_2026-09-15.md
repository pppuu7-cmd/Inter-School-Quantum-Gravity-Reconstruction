## Attack 1 — the covariance matrix has many eigenvalues, so it must contain many independent observables

Rejected at the parameter-identification level. A matrix can contain many measured components while being generated by a low-parameter Hessian. The source explicitly identifies `C=P^{-1}`, with `P` the second derivative of the same effective action. Once the background profile and leading action parameters are fixed, the leading eigenvalue pattern is a prediction/check of that Hessian rather than a new continuum coupling.

The many matrix entries provide statistical power to test the action's form, not automatically additional independent theory-space coordinates.

## Attack 2 — use a held-out covariance eigenmode not included in the fit

A held-out mode would be a valuable **model-validation statistic**, but if the source-qualified action predicts it entirely from `Gamma`, `omega` and the fixed volume, agreement would still not give an independent functional dependence on `g_k` versus `lambda_k`. It could falsify the truncation; it cannot split the couplings if it passes.

## Attack 3 — use transfer-matrix `lambda` as the missing cosmological coupling

Rejected by type semantics. The lattice effective-action parameter multiplying the linear volume term is tied to fixed-volume/Lagrange-multiplier conventions. The FRG `lambda_k=Lambda_k/k^2` is a dimensionless running cosmological coupling. The frozen stack contains no equation identifying the two.

Name equality is not a map.

## Attack 4 — use `mu` from the transfer-matrix potential as a second continuum parameter

In the de-Sitter minisuperspace action the potential/shape coefficient determines the classical width/profile. The direct 2024 rewriting expresses this same shape through `delta/delta_0=(omega_0/omega)^(8/3)`. Thus at leading large volume it is not independent of the already-used profile parameter `omega`.

## Attack 5 — use the nonzero `xi_2` subleading kinetic correction

The finite-regulator covariance analysis can fit a nonzero `xi_2`, but the same source reports that the large-volume transfer-matrix correction falls rapidly, becomes indistinguishable from numerical noise, and interprets the observed subleading corrections as discretization/finite-size effects rather than established continuum higher-curvature operators.

Therefore `xi_2` fails the frozen continuum-authority predicate. A new near-critical scaling study could reopen this class, but not by reusing the existing finite-volume coefficient as a continuum coupling.

## Attack 6 — the artificial covariance zero mode is a physical global massless mode

Rejected. The source explicitly attributes the zero mode to the fixed total-volume measurement constraint and removes it by allowing Gaussian total-volume fluctuations. It is a measurement artifact, not an independent physical excitation.

## Attack 7 — higher cumulants of the same global volume variable should solve the problem

This is not established by ITER089 itself. However, the direct fixed-volume minisuperspace action suggests a stronger identifiability question: after dimensionless rescaling, all orders of the same fixed-volume global distribution may depend on the same overall effective coupling. This should be tested algebraically in a separate prospectively frozen gate before higher cumulants are treated as independent constraints.
